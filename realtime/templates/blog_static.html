Running Real-Time AI on My Android Phone — No Cloud, No GPU

How I built a live image classifier with real-time breed detection using MobileNet, TFLite, and Flask — entirely on my phone.

✍ Satyam Sharma 📅 April 7, 2026 ⏱ 7 min read

I had an Android phone, Termux installed, and a question: how far can you push on-device AI without any cloud, server, or GPU? The answer turned out to be further than I expected. This is the story of how I built a real-time vision AI system — a breed detector and object classifier with live bounding box overlays — using nothing but my phone and Python.

This was pure vibe coding — no plan, no boilerplate, just curiosity and Claude Code guiding me through each step in the terminal.

1 Starting Point — MobileNet on a Phone

MobileNet V2 is a neural network designed specifically for edge devices — small enough to run on a phone CPU, powerful enough to classify 1000 different objects. I downloaded the quantized TFLite version (3.5MB) and wrote a classifier from scratch.

The model was already there in my repo but the files were empty (0 bytes). Classic. Downloaded the real thing and got it running in minutes.

2 Real-Time — Camera → AI → Overlay

The final step: make it live. Since Termux has no display, I built a Flask web server that the phone browser connects to. The browser captures frames using getUserMedia, sends them to Flask, and gets predictions back — then draws them as overlays on the live video.

3 What I Learned

Edge AI is more capable than people think A 3.5MB quantized model running on a phone CPU can classify 1000 categories with high accuracy. You don't need a GPU for inference.
Quantization is the key to edge deployment MobileNet V2 quantized (INT8) runs ~4x faster and uses ~4x less memory than the float version, with minimal accuracy loss.
The browser is a powerful edge AI interface getUserMedia + Canvas + fetch gives you a real-time computer vision pipeline accessible from any device on your local network — no app install needed.
Vibe coding works No plan, no boilerplate, no tutorial. Just a phone, a terminal, and curiosity. The best way to learn is to build something real.

4 Try It Yourself

Everything runs on any Android phone with Termux. No account, no cloud, no paid service. Here's how to replicate the full setup in under 15 minutes.

Requirements

Android phone Termux (F-Droid) ~200MB storage Internet (setup only)

Step 1 — Install Termux

Download Termux from F-Droid (not Play Store — the Play Store version is outdated).
→ f-droid.org/packages/com.termux

Step 2 — Install dependencies

pkg update && pkg upgrade -y
pkg install python git -y
pip install tflite-runtime numpy pillow flask

Step 3 — Download MobileNet model + labels

mkdir -p ~/tensorflow && cd ~/tensorflow

# Download quantized MobileNet V2 (3.5MB)
curl -L https://storage.googleapis.com/download.tensorflow.org/models/tflite_11_05_08/mobilenet_v2_1.0_224_quant.tgz | tar -xz

# Download ImageNet labels (1000 classes)
curl -o labels.txt https://storage.googleapis.com/download.tensorflow.org/data/ImageNetLabels.txt

Step 4 — Clone this project

git clone https://github.com/destortion/Edge-ai-computing.git ~/blog
cd ~/tensorflow

Step 5 — Classify any image

# From a URL
python classify.py "https://your-image-url.jpg"

# From your phone storage
python classify.py /sdcard/DCIM/Camera/your_photo.jpg

Step 6 — Run the live camera web app

cd ~/tensorflow/realtime
python app.py

Then open http://localhost:5000 in your phone browser. Point the camera at anything — it classifies in real time.
